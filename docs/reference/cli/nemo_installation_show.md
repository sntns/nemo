## nemo installation show

Show an installation: its bundle, target, parameters and credential sources

```
nemo installation show INSTALLATION [flags]
```

### Options

```
  -h, --help           help for show
      --json           print it as JSON on stdout
      --stack string   name of the stack (default: the current one)
```
