## nemo installation runs

List the actions run on an installation, oldest first

```
nemo installation runs INSTALLATION [flags]
```

### Options

```
  -h, --help           help for runs
      --json           print it as JSON on stdout
      --stack string   name of the stack (default: the current one)
```
