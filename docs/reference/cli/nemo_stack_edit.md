## nemo stack edit

Change a stack in the editor, the current one by default

### Synopsis

Open a stack in the editor, on its review: what is missing is marked, and
each line opens the step that changes it.

```
nemo stack edit [NAME] [flags]
```

### Options

```
  -h, --help   help for edit
```
