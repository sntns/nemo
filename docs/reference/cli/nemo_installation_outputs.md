## nemo installation outputs

List the outputs of an installation, the last value of each, or print one

```
nemo installation outputs INSTALLATION [OUTPUT] [flags]
```

### Options

```
  -h, --help           help for outputs
      --json           print it as JSON on stdout
      --stack string   name of the stack (default: the current one)
```
