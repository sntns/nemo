# Extension schemas

One JSON schema per extension nemo reads, named after the extension's key. `Extension.Schema` names the file; every value read from or written to `custom` is checked against it. Nothing is fetched from a schema's `$id`.

The spec defines only `output`, an output of the installation's own last runs. |
